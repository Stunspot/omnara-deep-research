# Release notes

## 1.0.0 - standalone public edition

This release publishes the curated Omnara Deep Research skill as a focused standalone source tree with:

- the complete skill doctrine, persona, references, knowledge, fallbacks, schemas, campaign template, and standard-library Python helpers;
- customer installation, verification, first-run, workflow, prompt, campaign-vault, troubleshooting, lifecycle, privacy, limitation, support, contribution, and maintainer guidance;
- a multi-page GitHub Pages product and documentation experience;
- distinct README, Pages, and social-share artwork;
- exact-commit documentation, accessibility, and adversarial verification receipts.

The release does not claim universal host installation, automatic access to sources, semantic citation correctness, exhaustive coverage, a fixed research scale, or independent fresh-host qualification beyond the evidence named in the final receipts.

The standalone history descends from the public Nova + MIND 1.0.0 contest source snapshot identified in [README.md](README.md).
