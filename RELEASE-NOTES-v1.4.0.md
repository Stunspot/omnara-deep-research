# OMNARA Deep Research 1.4.0

This is an owner-authorized product update from 1.3.1.

Question and search planning; ordinary document, text PDF, image, link and note intake; side-by-side source reading and notes; findings with source links; an editable cited answer and readable export.

Ask a question, add a useful document or pasted passage, select a finding, and use it in your answer. The app does not invent research conclusions.

Existing native state and advanced views are retained. User-facing work no longer requires constructing a prepared exchange packet. File intake is specific to the product task and is optional.
